# Keyboard Shortcuts

Anki-style hotkeys for the study view.

| Key | Action |
|---|---|
| `Space` | Flip between Front ↔ Back |
| `Enter` | Front: reveal answer. Back: submit **Good** (rating 3) |
| `Ctrl+Enter` | Reveal the answer, or submit **Good** when the answer is shown |
| `Backspace` | Submit **Again** (rating 1) |
| `1` `2` `3` `4` | Again, Hard, Good, Easy (`2` and `4` do nothing on a new card's first review and on cards repeated after Again, which only offer Again and Good) |
| `←` / `→` | Navigate back / forward through answered cards (cannot browse forward beyond unanswered cards) |
| `Z` / `Ctrl+Z` | **Undo** the last card rating and restore its exact previous SRS state, or the last send to back, suspend or reset and skip (not wrap up) |
| `R` / `S` | Replay vocabulary / sentence audio |
| `E` | Edit the current card |
| `B` | **Send to back**: move the card on screen to the end of the session without rating it |
| `P` | **Suspend** the card on screen (asks first) |
| `W` | **Wrap up** the session, or cancel wrap up: while on, no more new cards, only the *Again* cards still to clear and the next 5 reviews |

In the AI discussion chat, `Enter` sends a message; `Shift+Enter` or `Ctrl+Enter` adds a new line.
